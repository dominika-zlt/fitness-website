FITLIFE WEBSITE — QUICK START

FILES
- index.html = main website
- styles.css = colours, fonts, layout and design
- script.js = mobile menu and small interactions
- disclaimer.html = starter health disclaimer
- privacy.html = starter privacy page

HOW TO CUSTOMISE
1. Open index.html in a text editor such as Notepad, VS Code or an online editor.
2. Change "FitLife" to your own brand name.
3. Replace the text inside each section with your own information.
4. Replace the placeholder image areas with real images.
5. Duplicate workout, recipe or product cards to add as many items as you want.
6. In the Guides section, replace the Payhip links with your actual product checkout links.
7. Change colours in styles.css under :root.

FREE HOSTING OPTIONS
- GitHub Pages
- Netlify
- Cloudflare Pages

SELLING DIGITAL GUIDES
A static website cannot process card payments by itself. The easiest setup is:
Website -> Buy button -> Payhip/Gumroad/other checkout -> customer receives your PDF.

IMPORTANT
Before publishing health or weight-loss content, avoid guaranteed health/weight-loss claims and make sure your content is accurate. Update the disclaimer and privacy pages for your actual business.

IMAGE REPLACEMENT EXAMPLE
Replace:
<div class="hero-placeholder"> ... </div>

With:
<img src="images/your-photo.jpg" alt="Fitness" style="width:100%;border-radius:28px;display:block;">

Then create an "images" folder and put your image inside it.
